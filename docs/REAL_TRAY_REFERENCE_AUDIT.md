[Microsoft notification area APIs](https://learn.microsoft.com/en-us/windows/win32/shell/notification-area) let an app register/modify/delete its own icon. The GetRect API needs a known identity and does not enumerate. A callback is version-dependent and cannot be inferred by reading minimized windows or icon text. The [read-only UI Automation follow-up](REAL_TRAY_BRIDGE_POC.md) saw zero buttons on both auto-hidden taskbars and in the hidden XAML overflow HWND. There was no complete identity, pixel stream, callback or event stream to integrate through that path. No deliberate Deskland hide was performed during that trace.
