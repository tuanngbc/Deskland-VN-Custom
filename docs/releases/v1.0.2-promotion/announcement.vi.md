# TLauncher 1.0.2 đã phát hành

Unified Spotlight kết hợp tìm nhanh và thư viện toàn màn hình có thư mục, ghim Dock và chỉnh cách mở. Cache icon mới và quản lý bề mặt đồ họa giảm công việc lặp lại. Cài tốc độ chung, tôn trọng giảm chuyển động và chọn kính mờ khi Windows hỗ trợ.
