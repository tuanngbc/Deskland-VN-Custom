**常用应用随手可开，桌面按自己的习惯来布置。** TLauncher 是面向 Windows 11 的免费开源桌面工具，主要采用 Rust 原生开发。它将受 macOS 启发的 Dock 和台前调度与熟悉的 Windows 操作方式结合起来，动态壁纸和日常工具也可以按需开启。v1.0.2 的主角是统一的 Spotlight：快速搜索和全屏应用库，现在可以在同一个界面中切换。

## ✦ 统一 Spotlight：随手一搜，随时启动

按 **Alt + Space** 打开 **紧凑 Spotlight**，输入应用名称、已建立索引的文件名或系统工具，用方向键选择，再按 **Enter** 打开。想浏览所有应用，就点击 **Dock 上的放大镜**，在这块屏幕上打开 **全屏 Spotlight**。应用库借鉴 Launchpad 的布局，可滚动或用键盘翻页；点击应用即可启动，点击空白处或按 **Esc** 可关闭。

![TLauncher v1.0.2 浅色主题下的全屏 Spotlight 应用网格](https://raw.githubusercontent.com/tuanngbc/TLauncher/v1.0.2/docs/images/showcase/v1.0.2/spotlight-fullscreen-light.png)

*v1.0.2 的全屏 Spotlight，使用示例应用库。*

搜到一半想换个视图？按 **F6** 即可切换，已经输入的关键词会保留。打开 **设置 → 快捷键与实用工具 → Unified Spotlight**，可以分别设置快捷键和 Dock 的打开模式，也可以让 Dock 跟随快捷键设置。

### 应用怎么摆，由你决定

Spotlight 会从开始菜单和 Windows AppsFolder 自动发现应用。遇到未收录的便携软件，可在应用库的管理菜单中手动添加 **EXE** 或 **LNK**。右键应用即可重命名、更换图标、加入收藏、固定到 Dock 或隐藏。在布局编辑模式下，可以拖动应用调整顺序，也能把同类应用放进文件夹。

## 动效快慢，随你的节奏

鼠标悬停时 Dock 图标会放大；Dock 会随内容调整大小，也可自动隐藏，为窗口腾出空间。Spotlight 的打开与关闭、应用文件夹和页面切换，以及开始菜单、右键菜单、控制中心和日历，都有各自的过渡效果。

在 **设置 → 动画效果** 中可开启或关闭动画，也可以在 **0.25× 至 2×** 之间调整速度。新配置默认 **0.70×**，原有设置会保留。你也可以让 TLauncher 遵循 Windows 的减少动态效果偏好。

## 常用内容，无需反复加载

开始菜单、Spotlight 与 Dock 共用图标缓存，重新打开应用后也可以复用已保存的图标。Spotlight 会复用绘图资源，关闭时释放界面表面，减少不用时的绘制工作。实际资源占用会随硬件、显示器和壁纸而变化。[资源优化说明](https://github.com/tuanngbc/TLauncher/blob/v1.0.2/docs/TLAUNCHER_RESOURCE_OPTIMIZATION_REPORT.md)。

## ⬇ 在 Windows 11 上开始使用

**运行要求：** Windows 11 x64；动态壁纸需要 OpenGL 3.3；完整设置界面需要 Microsoft Edge WebView2 Runtime。无需安装 Rust 或其他开发工具。

1. 在 **Assets** 中下载 [TLauncher-1.0.2-win-x64.zip](https://github.com/tuanngbc/TLauncher/releases/download/v1.0.2/TLauncher-1.0.2-win-x64.zip)。**Source code** 包用于查看或自行构建源代码。
2. 将**整个压缩包**解压到准备长期使用的文件夹，在其中运行 `TLauncher.exe`，保留所有随附资源。
3. 从 Dock 或系统托盘打开 **设置**，启用需要的组件。如希望登录后自动运行，可以打开 **系统 → 随 Windows 启动**。

**初次体验建议：** 在 Windows **设置 → 个性化 → 颜色** 中开启 **透明效果**，体验磨砂玻璃；喜欢动效的话，可在 **辅助功能 → 视觉效果** 中开启 **动画效果**。TLauncher 可从 **0.70×** 开始尝试，主题随喜好选择，先用 **Alt + Space** 打开紧凑模式、用 Dock 打开全屏模式。窗口最小化和还原保持 Windows 默认效果，自动启动按需开启。

| 默认快捷键 | 操作 |
| --- | --- |
| Alt + Space · F6 · Esc | 打开或关闭 Spotlight · 切换模式 · 返回或关闭 |
| 方向键 · Enter | 选择并打开搜索结果 |
| Ctrl + Shift + S | 截图并编辑 |
| Ctrl + Shift + R · Ctrl + Shift + P | 开始或停止录屏 · 暂停或继续 |
| Ctrl + Alt + Shift + F12 | 恢复当前会话的 Windows 任务栏 |

**从 1.0.1 升级：** 退出旧版，备份安装目录和 `%USERPROFILE%\.deskland-rs`，再完整解压新版。保留当前配置，即可继续使用壁纸、显示器布局、固定应用和快捷键。若 EXE 路径改变，关闭后重新开启随 Windows 启动即可刷新启动路径。

**回退到旧版：** 先关闭新版自动启动并退出，恢复 [1.0.1 安装包](https://github.com/tuanngbc/TLauncher/releases/tag/v1.0.1) 和所需的升级前配置备份，再在旧版中按需开启自动启动。更多步骤见 [使用指南](https://github.com/tuanngbc/TLauncher/blob/main/README.zh-CN.md)。

### 使用小提示

- 磨砂玻璃取决于 Windows 桌面合成、显卡驱动和透明效果设置。不支持时会自动使用备用背景。
- 受保护的窗口可能无法预览或捕获。图标清晰度取决于原图；输入法表现和部分原生界面文字也会因环境而异。
- 窗口最小化和还原由 Windows 使用默认过渡效果处理。
