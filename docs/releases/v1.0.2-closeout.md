# TLauncher v1.0.2 development closeout

Final feature base: [3a3e512](https://github.com/tuanngbc/TLauncher/commit/3a3e51202f4cd34708ebd3d2cffca75b2f034f94). Preserve [Actions evidence](https://github.com/tuanngbc/TLauncher/actions/runs/45430738826) and [native screenshot provenance](../images/showcase/v1.0.2/README.md).

- **Unified Spotlight, glass, library, activation and motion:** shipped in v1.0.2 after Windows Actions gates. Compatibility materials and accessibility policies remain available.
- **Scale minimize/restore:** the owner retested 3a3e512 and still saw native minimize/restore. Owner acceptance **FAIL**. Prior CI showed matched compositor pixels in its limited fixture; it did not reproduce the owner's machine. Release uses Windows Default and hides Scale from the normal profile. Existing implementation is preserved in TEST. Follow-up: deferred, not fixed.
- **Genie:** not implemented. Deferred.
- **Stage Peek:** not started; a future version only.
- **Performance:** verified CI lifecycle regression checks, including repeated Spotlight surface opens and resource release. The owner's lower-RAM observation is qualitative; whole-app RAM/GPU/CPU targets and hardware compatibility remain unverified.
- **Screenshots:** actual native output on isolated test fixtures and historical masked dual-display owner imagery, clearly attributed. No approved runtime motion recording for v1.0.2.
- **Milestone closed for feature development.** Do not reopen 1.0.2 or start 1.0.3 automatically. Future release and deployment require owner authorization.
