It brings a macOS-inspired Dock and Stage Manager to familiar Windows workflows, with live wallpapers and everyday tools you can turn on separately. In v1.0.2, a quick search and a full-screen app library finally share the same front door: Unified Spotlight.

## ✦ Unified Spotlight: one search, two ways in

Press **Alt + Space** for **Compact Spotlight**. Type an app name, an indexed file or a system tool, choose a result with the arrow keys, and press **Enter**. To see everything at once, click the **magnifying glass on the Dock** for **Fullscreen Spotlight** on that display. Browse the Launchpad-inspired library by scrolling or using the keyboard, click an app to launch it, and click empty space or press **Esc** to close it.

![TLauncher v1.0.2 Spotlight with a full-screen app grid in the light theme](https://raw.githubusercontent.com/tuanngbc/TLauncher/v1.0.2/docs/images/showcase/v1.0.2/spotlight-fullscreen-light.png)

*Fullscreen Spotlight in v1.0.2, with a sample app library.*

Already typing? Press **F6** to switch views without losing your query. Under **Settings → Shortcuts & Utilities → Unified Spotlight**, choose a mode for the shortcut and a different one for the Dock, or have the Dock follow the keyboard shortcut.

### Your apps, in your own order

Spotlight discovers apps from the Start Menu and Windows AppsFolder. If something is missing, use the library menu to add an **EXE** or **LNK**, including portable apps. Right-click an app to rename it, change its icon, add it to favorites, pin it to the Dock or hide it. In layout editing mode, drag apps into the order you want or group them in folders.

## Motion at your own pace

Dock icons grow on hover, and the Dock can resize or tuck away to make room for your work. Spotlight opens and closes with a transition, folders and pages move between views, and Start, context menus, Control Center and Calendar each have their own motion.

Open **Settings → Motion effects** to turn animations on or off and set the speed anywhere from **0.25× to 2×**. New profiles start at **0.70×**; existing preferences carry over. TLauncher can also follow the Windows reduced-motion preference.

## Less work between launches

Start, Spotlight and Dock share an icon cache that carries over between sessions, so they can reuse icons instead of fetching them on every open. Spotlight also reuses its graphics setup, releases surfaces when you close it, and avoids drawing work it no longer needs. Actual resource use depends on your hardware, displays and wallpaper. [Resource notes](https://github.com/tuanngbc/TLauncher/blob/v1.0.2/docs/TLAUNCHER_RESOURCE_OPTIMIZATION_REPORT.md).

## More than an app launcher

These tools are already part of TLauncher. Pick the ones that make your desktop more useful.

**Keep your windows in reach.** Pin apps, shortcuts or commands with arguments to the Dock. In **Stage Manager**, click a preview at the edge of the screen to switch windows, or use the arrows to browse a group. The **Start Menu** puts pinned, recent and frequent apps in one place. Switch to **Windows compatibility** if you prefer the original Start menu, taskbar and tray.

![Stage Manager perspective cards showing sample windows at two display scaling levels](https://raw.githubusercontent.com/tuanngbc/TLauncher/v1.0.2/docs/images/showcase/stage.webp)

*Perspective cards with sample windows at two display scaling levels.*

**Make room for a view.** Pick from **16 interactive live wallpaper themes** under **Settings → Wallpaper**. Set local weather or use offline conditions; in supported scenes, sunlight and shadows follow the time of day and the sun's position. Under **Displays**, sync a theme, set one per monitor, or stretch a **panorama** across landscape and portrait screens. Place the Dock, Stage and two desktop clocks on the displays you choose.

**Everyday tools are close by.** Open Control Center from the Dock arrow, click the date and time for a monthly calendar, or enable CPU, GPU, RAM and network indicators. Use the screenshot editor to crop, annotate or mask information; record an area as MP4 for a quick walkthrough. Settings is available in Vietnamese, English and Simplified Chinese.

## ⬇ Get started on Windows 11

**You'll need:** Windows 11 x64, OpenGL 3.3 for live wallpapers, and Microsoft Edge WebView2 Runtime for the full Settings experience. No Rust or developer tools are required.

1. Download [TLauncher-1.0.2-win-x64.zip](https://github.com/tuanngbc/TLauncher/releases/download/v1.0.2/TLauncher-1.0.2-win-x64.zip) from **Assets**. The **Source code** archives are for browsing or building the project.
2. Extract the **entire** ZIP to a folder you plan to keep. Run `TLauncher.exe` from that folder so it can find its companion files.
3. Open **Settings** from the Dock or system tray. Enable the tools you want. To start at sign-in, turn on **System → Start with Windows**.

**A good starting point:** Enable **Transparency effects** in Windows **Settings → Personalization → Colors** for frosted glass. If you like motion, turn on **Animation effects** under **Accessibility → Visual effects**. In TLauncher, try **0.70×**, use your preferred theme, and start with Compact on **Alt + Space** and Fullscreen on the Dock. Keep standard Windows window transitions; sign-in startup is optional.

| Default shortcut | What it does |
| --- | --- |
| Alt + Space · F6 · Esc | Toggle Spotlight · switch modes · go back or close |
| Arrow keys · Enter | Select and open a result |
| Ctrl + Shift + S | Capture and edit a screenshot |
| Ctrl + Shift + R · Ctrl + Shift + P | Start/stop a recording · pause/resume |
| Ctrl + Alt + Shift + F12 | Restore the Windows taskbar for this session |

**Upgrading from 1.0.1:** Quit the old version and back up its installation folder and `%USERPROFILE%\.deskland-rs`. Extract the new package in full and keep that profile so you retain your wallpapers, displays, pins and shortcuts. If the EXE path changes, toggle Start with Windows off and back on to update its target.

**Going back:** Turn off startup in the new version and quit it. Restore the [1.0.1 package](https://github.com/tuanngbc/TLauncher/releases/tag/v1.0.1) and the pre-upgrade profile backup if needed, then re-enable startup in the old version. The [user guide](https://github.com/tuanngbc/TLauncher/blob/main/README.en.md) has help with setup and troubleshooting.

### Good to know

- Native glass depends on the Windows compositor, the graphics driver and the transparency setting. A fallback surface is used when glass is unavailable.
- Windows may block previews or capture of protected content. Icon sharpness depends on the original icon; input method behavior and some native labels vary by environment.
- Windows handles window minimize and restore with its standard transitions.
