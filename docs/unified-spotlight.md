# Unified Spotlight (v1.0.2)

Unified Spotlight runs on TLauncher's existing UI thread. Compact is the original quick search surface; the full-screen native surface adds a paginated application library and an editable Windows search field. The Dock sends its physical monitor position to the same Spotlight owner. Start retains its own surface and Windows-key policy.

- `catalog.rs` builds shared snapshots from Start Menu entries and Windows AppsFolder (packaged apps). Start Menu links are classified by resolved target metadata; document, website, administrative and installer/helper targets are not automatic application tiles. Exact Windows app aliases and identical command targets are deduplicated while manual entries and argument-specific links remain. Discovery and scoped file enumeration run off the UI thread.
- Both Spotlight views and Start reuse one bounded decoded-raster cache, which can draw ready icons in their first paint. The shared shell/custom source cache also serves Dock and stores checked, lossless premultiplied BGRA in `cache/app-icons-v1` within the active profile. L1 budgets are 24 MiB for source rasters and 16 MiB for launcher rasters; the L2 budget is 128 MiB. The worker revalidates source stamps, shortcut icon location, package versions, custom assets and size tiers. Startup schedules a bounded default-page prefetch after initial desktop presentation. Actual off-session hit rate and first-page readiness are measured separately from these policy limits.
- `fullscreen.rs` owns overlay geometry, search generations and keyboard navigation. On a compatible Windows 11 compositor the full-screen renderer uses a passive HostBackdrop companion and a separate GPU surface for premultiplied UI. Dirty regions upload only changed foreground pixels; the host does not capture the screen. DirectComposition animates the foreground independently. The native editor still receives Windows keyboard and text input; its visual is composited with the rest of the search field. Compat mode uses a one-time in-memory snapshot if the native path cannot initialize. With transparency disabled or in high contrast, the display uses a solid material. See the [reference and evidence audit](SPOTLIGHT_GLASS_REFERENCE_AUDIT.md).
- Compact continues to use its small layered window and fades/scales its cached pixels during a transition. Both modes honor the existing animation setting and Windows reduced-motion preference. F6 carries the query between surfaces without rewriting the activation preferences.
- `library.rs` stores logical ordering and folder membership. The existing preserving config writer saves `spotlight` and `spotlightLibrary` in the active profile. Custom icons and Dock pins reuse their current TLauncher settings. Hiding or removing a library entry never deletes the original file.

## Historical candidate workflow

After successful CI the developer retrieves and verifies the exact artifact, extracts it in a dedicated UAT directory and prepares one TEST shortcut. Only the owner clicks that shortcut; running the candidate EXE directly would omit profile isolation. `owner-uat.ps1` verifies the candidate version, SHA and commit, checks same-session process ownership, uses the existing `--quit` command and waits for the singleton to release. It starts the trial with a separate `tuanpc-desk-trial-…` profile and restores the previously running production when the candidate exits. It never force-kills, overwrites production or modifies production startup. If recovery fails, exit the candidate normally and use the supplied RESTORE-PRODUCTION shortcut. No local build or automated verification is permitted.

1. In **Settings → Shortcuts & Utilities → Unified Spotlight**, set a mode for the existing Spotlight keyboard shortcut (default **Alt+Space**). Check that it toggles the selected mode, including if the chord is customized. Type a query and press **F6** twice to verify it is preserved in both directions. **Esc** closes the overlay, or goes back from a folder.
2. Set the Dock magnifier to Compact, Fullscreen or Follow the keyboard shortcut mode. Click it on each monitor. Changing these modes in Settings should affect the next activation without re-registering the keyboard shortcut. The default for existing configurations is Compact by keyboard and Fullscreen by Dock, unless the user already set the Dock to Compact.
3. Test an installed Win32 app, an AppsFolder app, a portable EXE and a LNK with arguments. Verify Add, Pin, Hide/Restore, New Folder, drag, remove, and the app-specific menu. No automated test launches the owner's apps.
4. Check glass over both wallpaper and an open window, focus return, portrait and landscape displays at mixed scales, and behavior during a display change. Compare first-open and repeated-open icon readiness. The OS controls blur radius on HostBackdrop; the existing radius slider applies to compatibility mode. Report unreadable areas or missing apps with personal names hidden in captures.

## Evidence boundaries

The Windows workflow distinguishes cache and configuration tests, the isolated native library and activation fixtures, and the compositor proof using synthetic stripe detail. An unavailable compositor is recorded as blocked, and API success is not proof of blur. The user-visible glass, frame pacing, real app discovery, mixed display topology and production handoff still require owner UAT. The released Spotlight behavior is described above. Owner acceptance limitations for the separate Scale experiment are recorded in the release closeout.
