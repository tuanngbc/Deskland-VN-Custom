The three owner-provided crops showed an app-sized Spotlight cell next to smaller individually framed controls and repeated Stage title prefixes. The redesign uses a separate grid with shared theme colors, stable utility hit regions during app magnification, and one or two rows configured independently by display. The app pipeline still uses real Shell icons. The Stage caption strips a shared fixture prefix only if it can retain a distinguishing tail; other long titles use measured ellipsis. The tooltip keeps the full title. DWM thumbnails preserve their aspect ratio and remain in the existing window-management path.

Control Center, the window picker and the network, Bluetooth and quick settings views use anchored native panels. Audio and calendar use actual Windows child controls inside the new panel chrome; they can still have Windows-specific styling. Network and Bluetooth show provider state and delegate connection changes to Windows. The material is premultiplied alpha / translucent panel chrome; Windows backdrop blur is not claimed. Use the existing safe-geometry and restore tests to distinguish drawing changes from window management.

CPU, RAM, GPU, receive and transmit can be selected per output. Metrics are off by default. Inline metrics keep a stable hit target and fall back to a glyph or overflow on narrow layouts. A single inline timer serves visible Dock surfaces and a metrics panel samples only when open. Both share the taskbar monitor's sampler and counters. The follow-up rates limit rendering on each output independently while the visible inline displays retain one sampler timer. The prior Dock idle and Stage idle `SCOPED_PASS` results are unchanged and do not measure this new metrics feature.
