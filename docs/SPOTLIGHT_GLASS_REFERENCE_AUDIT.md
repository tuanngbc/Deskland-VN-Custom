- [Microsoft material contract](https://learn.microsoft.com/en-us/windows/apps/develop/ui/materials): an in-app acrylic brush is not a desktop backdrop. [Windows 11 SystemBackdrop](https://learn.microsoft.com/en-us/windows/apps/develop/ui/system-backdrops) also has policy and accessibility behaviors.
- [DWM attributes](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute): host backdrop opt-in is a Windows 11 feature. System backdrop type requires build 22621; explicit premultiplied redirection bitmap alpha requires build 26100. DWM may substitute a material or drop blur based on system policy, so acceptance must examine actual pixels.

## TLauncher baseline and alternatives

At `a058298`, Fullscreen Spotlight samples the monitor once with `capture_glass`, CPU-frosts a downsampled buffer, and redraws the result behind GDI controls and a native EDIT in a compatible bitmap. The dock shares the capture/frost helpers; it is not a live compositor. Compact has its own small layered window. The buffered dirty-region work prevents repeated captures on hover but it cannot retain live changes behind the launcher.

- **A, HostBackdrop:** the fixture uses `CreateDesktopWindowTarget` on a passive Win32 companion window, `CreateHostBackdropBrush`, and a separate premultiplied foreground. The host's tint visual is independent of foreground layout and input. The optical check compares small-stripe detail against distant color spread; reducing both by the same amount only indicates tint.
- **B, wallpaper-derived GPU blur:** `src/gpu_present.rs` shares the wallpaper's OpenGL/D3D texture with its own DirectComposition target on the owning thread. There is currently no safely exposed, independently retained per-monitor output for Spotlight. Sharing the GL-bound texture would couple lifecycle/fences and a paused or disabled wallpaper would leave no source. No CPU-readback substitute or extra renderer is introduced.
- **C, Desktop Acrylic:** the fixture requests the public transient-window system backdrop and extended margins on a separate passive HWND. It measures actual pixels because an inactive window or Windows policy can substitute a solid surface. Mica is not substituted.

Fixture acceptance is only evidence for the renderer and input-free surface tested. A blocked compositor or low color retention is not a visual pass; wallpaper hue, input and multi-monitor behavior remain part of owner UAT.
