# Deskland P0 daily-use UAT

Base: `e203cba0b2ad64fdb48d282f713727116ebbb8c4`. Keep PR #1 draft, keep the stable installation and the current user profile intact.

- **Start:** Win-up captures the actual signed desktop pointer coordinates in the hook. The Dock resolves that monitor first, then foreground, then primary. Ctrl+Alt+Space uses the same route. A second invocation dismisses Start on the same monitor or moves the same Start window to another monitor. The resting Dock layout supplies the button's left edge and glass top for a bottom Dock. Side Docks open inward. The app clamps the panel to the work area and pins the baseline while results resize.
- **Status:** One existing worker reads Windows WLAN/interface state and the current Core Audio endpoint; the existing 5 s controller tick requests the light sample only when needed. Full utility queries and audio controls feed the same status. Unknown signal gets no filled bars; the 0–100% thresholds, Ethernet, missing adapter, disabled adapter and mute have separate shapes. SSID is display-only and never logged by the new code. The trial cannot write real audio settings.
- **Stage:** The default is live DWM. In stacked Stage, open a card's context menu and choose **Ảnh phối cảnh · chụp nhóm một lần**. The request attempts a frame for each rendered member, at most five, then projects those textures with near/far ratio 1.310 at 28° (front). All windows must be visible, uncloaked, unminimized, and report unprotected affinity. The pipeline never captures a desktop and never saves a product snapshot. One job and one complete raster are retained across monitors, with at most five 360px sources transiently in RAM. A failed member keeps the entire group on live DWM. Group/layout changes, hide, and exit discard the snapshot. The right-side projection is mirrored without reversing content. Hover reduces yaw; Reduced Motion keeps it steady. The fallback and member picker remain available.
- **WGC diagnostics:** The CI checks use a painted, owned HWND with a separate MTA capture worker while the window owner pumps events. If needed, it compares a regular overlapped HWND with a tool window. The diagnostic records top-level identity, visibility, cloak and affinity status and the first failing API/HRESULT. An explicitly selected trial diagnostic can write only owned test-window output. That result does not certify Stage rendering for external apps. The interop factory uses the typed `GraphicsCaptureItem` interface and D3D11 BGRA hardware device. Sources fail closed; there is no desktop-copy, PrintWindow, protected-content bypass or retry loop.
- **Tray:** The caret still opens Control Center by default. **Ứng dụng chạy nền / Khay ứng dụng** separates restorable minimized windows from the Explorer notification area. A read-only UI Automation probe on the owner desktop with both Explorer taskbars hidden returned 0 descendants from both taskbar roots and no mounted overflow HWND. UI Automation does not expose callback IDs or complete icon pixels. Explorer compatibility remains available as an explicit action; Deskland does not claim native tray replacement.

Reference audit (independent implementation):

- [StageDock-Windows d8ca4de](https://github.com/ImmanuelDeo/StageDock-Windows/tree/d8ca4de0b22e1c083b91aa00f344622d9f1bd370): pinhole UV and bilinear sampling, depth shading, soft shadows and screen-space interaction. Its `PrintWindow` / screen-copy fallback was not adopted.
- [Seelen UI fae55d7](https://github.com/eythaann/Seelen-UI/tree/fae55d7510aa2503bd81dbc8f53b61677669342e): AGPL; its Rust service receives Explorer notifications from an injected DLL/shell hook and uses icon identity metadata. That path needs a separate approved VM and license review.
- [ManagedShell 8552220](https://github.com/cairoshell/ManagedShell/tree/855222035e927910ca53fd3215caef056337a048): Apache 2.0. Its Explorer compatibility collector temporarily changes autotraying and reads the legacy toolbar in Explorer's process. Its shell-replacement path listens on a native tray host. Neither path meets the current constraint of leaving Explorer and its settings untouched.
- [RetroBar 545f9f2](https://github.com/dremin/RetroBar/tree/545f9f2946bdd052236b4c6b730fdc73399e225b): Apache 2.0; the app uses ManagedShell as a dependency. It does not provide an independent public collector.

Manual trial: use the paired shortcuts; test Win with the pointer and foreground on different displays, same-monitor close and cross-monitor move, Win+E/R/D, different DPIs and Dock locations, live status, minimized restore, and Stage left/right on disposable apps. Avoid capture of private windows. Compare CPU, DWM GPU, Deskland GPU and handles with the same modules, coverage and window set. Restore the Windows taskbar with Ctrl+Alt+Shift+F12. Do not mark owner acceptance from CI or from the capture diagnostic alone.
