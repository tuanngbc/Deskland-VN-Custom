# Real tray: licensing and shell gate

No Seelen, ManagedShell or RetroBar code or binary was added. No injected DLL, private Explorer IPC interception, Explorer memory access, replacement shell/notification host, Registry or Startup change was performed. An IPC boundary would not by itself resolve AGPL obligations. Reuse of Apache-2.0 code would require checking provenance and including its notices.

The current desktop is not a disposable fixture. No isolated Windows VM with a separate Explorer session was available in this run. Before testing any alternative that touches Explorer internals on a production desktop, the owner directive requires an independent VM trial, verified rollback and crash recovery, license review, and separate owner approval. No production adoption is proposed from the present evidence.
